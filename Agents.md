# Threadly Project Instructions

## What is Threadly?
Threadly is a modern discussion platform where users connect through topic-based Spaces and share ideas through Threads. It’s designed to make conversations organized, meaningful, and easy to explore—whether you’re discovering new interests or engaging with your favorite communities. With a clean interface and structured discussions, Threadly helps people focus on quality conversations instead of noise. From casual sharing to in-depth discussions, Threadly makes community-driven interaction simple and engaging.

## Overview
Threadly is a social media platform built with React, Node.js, and PostgreSQL.

## Tech Stack
- Frontend: React, Material-UI, Vite
- Backend: Node.js, Express, Knex.js
- Database: PostgreSQL
- File Storage: Cloudinary

## Global Rules
- Use ES modules (import/export)
- Follow the existing file structure and component organization
- Follow consistent naming conventions (camelCase for JS, snake_case for DB)
